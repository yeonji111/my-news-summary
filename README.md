💡 프로젝트 기획 의도 (Motivation)
"AI가 코드를 작성하는 시대, 개발자의 역할은 '구현'에서 '설계와 조합'으로 진화하고 있습니다."
본 프로젝트는 자연어 지시어만으로 코드를 생성하는 바이브 코딩(Vibe Coding) 패러다임을 적극적으로 수용하여, 개발 생산성을 어디까지 끌어올릴 수 있는지 검증하기 위한 시도에서 출발했습니다.
데이터 핸들링의 표준인 Python을 기반으로, LLM 오케스트레이션 프레임워크인 LangChain을 융합하여 실시간 네이버 경제 뉴스를 수집하고 AI가 핵심 맥락을 관통하는 브리핑을 제공하는 RAG(검색 증강 생성) 기반 요약 봇을 구축했습니다.
단순한 기능 구현을 넘어, 최신 AI 가속 개발 흐름 속에서 엔지니어가 아키텍처를 어떻게 리드하고 복잡한 프롬프트 흐름을 제어해야 하는지 그 해답을 찾아가는 실험적인 프로젝트입니다.


🛠️ 기술 스택 선정 이유 (Tech Stack & Rationale)
- Vibe Coding (AI-Driven Development): 복잡한 보일러플레이트 코드 작성 시간을 최소화하고, 비즈니스 로직 설계와 프롬프트 엔지니어링 등 상위 수준의 아키텍처에 집중하기 위해 도입했습니다.

- Python: 방대한 패러다임의 AI 생태계 및 크롤링 라이브러리를 가장 빠르고 안정적으로 결합할 수 있는 최적의 환경으로 선택했습니다.

- LangChain: 단순한 LLM API 호출을 넘어, 수집된 뉴스 데이터를 벡터화(Embedding)하고 사용자 질의에 맞는 컨텍스트를 정밀하게 추출하는 RAG 파이프라인의 핵심 뼈대로 활용했습니다.
